# 在线书籍：布局、视觉与阅读交互

在生成在线书籍、章节 HTML 或按参考站点改版时读取本文件。以下规范提炼自参考站点的 Astro 源码快照；具体尺寸与颜色是可调整的起点，不要求复制品牌、封面、书名或插图。沿用目标项目的构建体系，不强制迁移到 Astro。

## 先确定页面范围

完整在线书籍采用“书籍首页 + 章节阅读页”。读者从首页了解主题与前置知识，再进入连续阅读；实验从章节中的相关位置进入。

- 若用户要求完整参考阅读体验，规划主题、字号、专注模式、章节导航、进度恢复、图片查看和高亮笔记，并逐项验收。受限功能应明确列出，不能只画按钮。
- 单章 HTML 保留排版、章节内目录、代码、图表及窄屏可读性；无需添加没有用途的全书导航、首页或笔记系统。
- 仅写 Markdown、正文或实验时，不扩展成网站开发。
- 多语言、账户同步、全文搜索、站点发布由实际需求决定。参考站点的该源码快照尚未实现全文搜索，不把搜索描述为已观察到的能力。

## 书籍首页

首屏围绕书本：书名、副标题、读者与前置知识、开始或继续阅读入口、作者与源码来源。可用一个与主题有关的机制图辅助理解；不要以无关动画、商业宣传或大量功能卡片占据首屏。

首屏之后给出有顺序的章节目录：章号、标题、一句具体学习目标和入口，标明起始章。章节数由内容产生，不固定为参考书的十章。随后提供配套实验入口与来源、许可证等必要信息。只有真实存在的下载文件才显示 PDF/EPUB 下载按钮。

动态图若采用步骤播放，动画应沿真实的数据流或控制流移动。提供暂停和手动步进，遵循减少动画的系统偏好，离开视口后停止无用更新。静态图也可以完成同一教学目的。

## 章节阅读布局

桌面采用三列：左侧全书章节导航，中间正文，右侧本章提纲。顶部为轻量固定栏，显示书籍入口与必要的阅读控制。侧栏各自滚动，滚到边缘时不意外带动正文。

当前章节与当前小节有明确但克制的选中状态。提纲从实际标题生成，遵循层级，跳转时标题不被固定栏遮挡。正文下方给出上一章与下一章；末章回到目录，不生成不存在的下一页。

缩窄页面时依次收起右提纲与左章导航，通过正文内目录或可关闭的导航面板保留访问能力。不要强行压缩三列直到正文过窄。

参考源码中的起始尺寸：

| 项目 | 参考值 | 使用原则 |
| --- | --- | --- |
| 阅读区域最大宽度 | 1600px | 超宽屏居中，正文不无限拉长 |
| 常规三列 | 245px / 弹性正文 / 230px | 中列使用 `minmax(0, 1fr)`，避免长代码撑开网格 |
| 正文容器最大宽度 | 870px，常规左右内边距 54px | 这是含内边距的容器宽度；按实际字体调整可读行宽 |
| 顶部栏 | 桌面 78px，手机 72px | 锚点、进度条与侧栏偏移应一致 |
| 1000px 及以下 | 隐藏右提纲，提供移动阅读控制 | 平板仍可保留左章导航 |
| 760px 及以下 | 单列，隐藏左章导航，正文左右留白 24px | 导航面板继续可达 |

这些断点不是设备分类标准；长标题、字号放大和中文内容可能要求更早折叠。检查最终级联样式，不只看第一个媒体查询。

移动阅读控制可固定于底部，包含目录、字号、专注模式和笔记入口。正文预留工具栏高度与 `safe-area-inset-bottom`，保证最后一段、脚注和页间导航不被遮住。触控、横屏和软键盘展开时都要检查。

## 配色与排版

使用温和背景、清晰正文、低对比辅助信息和少量强调色。边界以细线与留白区分，章节正文不装进一连串卡片。

| 语义 | 浅色参考 | 深色参考 |
| --- | --- | --- |
| 页面背景 | `#fcfcf9` | `#18191c` |
| 次级表面 | `#f2f3ed` | `#222429` |
| 正文 | `#20231e` | `#eeeef0` |
| 辅助文字 | `#62675d` | `#aaadb6` |
| 分隔线 | `#dedfd7` | `#383b43` |
| 强调色 | `#d8ed7a` | `#aac7ff` |

强调底色与链接文字颜色分别定义，不能直接将浅黄色用作白底小字号文字。实际配色仍需检查正文、链接、焦点和代码高亮的对比度。

参考站点采用 Manrope 界面字体与 Newsreader 正文字体；中文依赖系统回退。新页面应明确中文回退字体，并在目标系统检查，不能假设拉丁字体覆盖汉字。可使用已有系统字体；采用自托管字体时检查文件与许可证，不默认请求外部字体服务。

正文基准字号参考 `1.0625rem`，行高约 `1.68`，段落下间距约 `1.3em`。章节标题突出，二三级标题层级清楚；二级标题前增加留白和细分隔线。数值按实际语言调整，不追求像素级复刻。

阅读字号调整应同时影响正文、代码和表格，不能只放大段落后让代码仍不可读。用户字号选择可持久保存；存储不可用时仍能在当前页使用。

## 代码、实验卡、表格与公式

代码使用等宽字体与真实语法高亮，保留原始缩进、空行和字符。宽代码默认允许局部横向滚动，按内容提供换行开关；切换换行只影响展示，不能改写源码。保留按列对齐的轨迹示意时，不强制折行。

复制操作从原始代码文本取得内容，排除行号、工具栏、语言标签及其他装饰。复制失败应提供选中代码的明确提示，不能显示虚假的“已复制”。若要显示行号，将它与可复制代码分离。

实验卡采用轻底色和细侧边线，展示编号、问题、任务与实现链接；不要仅以颜色区分提示、限制和失败。实验步骤仍紧邻所解释的机制。

表格保留语义表头，宽表在自身容器中滚动，不能导致整页横向溢出。公式使用适合项目的数学渲染器，区分行内与块级公式；长公式允许局部滚动。脚注编号能跳到定义，并可返回引用处。核查这些功能经过 Markdown 渲染后仍成立。

## 图形语言与查看器

架构图用统一字体、色板、框与箭头建立跨章一致性。节点之间留出箭头和标签的空间；把长标签换行，不将整张图缩小到文字不可读。反馈与返回路径要可区分，箭头起终点与源码中的职责边界一致。

图下注明编号与含义，正文解释应观察的关系。截图、实验热图和曲线中的数据像素、数值及颜色编码不能为了适配主题而随意重绘或反色。

需要为网页改排 SVG 时生成独立展示版本，保留原图和来源入口。逐项核对标签、单位、箭头方向、图例和数值；文字与图有冲突时先说明或修正有依据的内容，不在视觉改造中悄悄改变结论。

复杂图支持点击放大、缩放、适配视口、拖动或滚动，以及打开原图。查看器要有关闭入口，支持 Escape，关闭后返回原触发位置。深浅主题切换应同时更新正文图和查看器中的展示版本。

## 阅读状态与笔记

完整阅读器将当前章节、稳定小节标识和小节内相对位置作为恢复依据，避免仅保存容易因字体变化失效的像素值。显式小节链接优先于历史位置。首页可显示“继续阅读”，普通章节链接不应无提示地跳往旧位置。

显示阅读进度时，以正文为范围，处理短章和已经到达文末的情况；专注模式隐藏干扰区域，但保留退出和导航能力。

提供高亮笔记时说明：本地保存还是服务器保存，作用于哪本书、语言和章节，清除站点数据会有什么后果。参考实现使用 IndexedDB 保存高亮及纯文本笔记，用浏览器本地存储保存主题、字号和阅读位置，不支持跨设备同步。

高亮用选中文本及邻近上下文定位。修改后的正文无法唯一定位时，将笔记保留为未匹配记录，不错误绑定到其他段落。保存与草稿要有清楚区别；提供删除撤销和 JSON 导入导出时，验证格式、版本和语言范围，避免静默覆盖冲突笔记。

参考实现的高亮范围是正文文字，包括行内强调和链接，不包括代码块、图、公式和脚注。使用者可以选择扩大范围，但应实际实现并测试；导入内容按数据处理，不能当作 HTML 执行。

## 内容来源与可维护性

书稿保持一份可编辑来源；网页、PDF 与其他输出通过构建读取它。标题提纲、章节导航及实验链接尽量从同一份元数据生成。展示适配层负责图注、资源路径和样式，不维护另一份易失同步的全文副本。

区分内容错误与展示错误。改布局时检查正文、代码和图注没有丢失；代码文本与实验文件有映射时验证一致性。多语言仅在有需求时添加，明确人工校订与未审校机器翻译；语言切换无对应锚点时回到章首，不能跳到无关小节。

## 可访问性、降级与部署

使用语义标题、导航名称、可见键盘焦点和跳过导航入口。弹窗妥善管理焦点，关闭后恢复。按钮有可理解的文字或无障碍名称；减少动画偏好下仍显示机制关系。

无 JavaScript 时正文、目录链接和实验链接仍可读；增强控件在初始化成功后再显示。存储失败、字体失败或图片加载失败时保留基本阅读路径及替代说明。

公开部署前按实际基路径检查章节、图片、脚本、样式及脚注链接；本地根路径通过不能证明 GitHub Pages 子目录可用。根据目标决定索引策略，不照搬原型站的 `noindex, nofollow`。发布操作仍需要用户授权。

## 验收方式

先完成实际项目的构建、类型或内容检查，再用浏览器检查代表性页面：

| 场景 | 必须观察的结果 |
| --- | --- |
| 首页与首章/中间章/末章 | 入口、目录、页间链接正确，无缺失章节 |
| 桌面、平板、手机与横屏 | 布局按需折叠，无整页溢出，底栏不遮正文 |
| 深浅主题与放大字号 | 段落、代码、表格和图片仍可读，布局稳定 |
| 目录跳转与返回 | 当前项准确，锚点不被顶部栏遮挡 |
| 代码复制与换行 | 粘贴结果和原始代码完全一致，失败有反馈 |
| 宽表、长公式、复杂图 | 可局部滚动或放大，数字与标签未改变 |
| 恢复位置与专注模式 | 显式链接优先，恢复可解释，退出入口可达 |
| 已实现的笔记功能 | 刷新后保存，草稿、冲突、失配和撤销符合说明 |
| 键盘、减少动画与脚本关闭 | 基本阅读路径可用，焦点行为合理 |
| 实际部署基路径 | 资源与内部链接完整，不依赖开发服务器兜底 |

可用 1440px、900px、390px 作为初始视口样本，但还须覆盖项目自身的断点。没有实际执行的交互不得记为通过。只更新本 Skill 时验证文档路由、来源和一致性即可；这不等于生成网站已完成视觉验收。
